# Jack Sun

AI-native operator building small, practical tools for research, trading workflows, and local automation.

I use agents as a workbench: turning repeated manual tasks into lightweight scripts, browser tools, workflow templates, and open-source utilities that are easy to inspect and run.

## Current Focus

- AI agent workflows: Codex, skills, memory, repo automation, review loops
- Trading research tools: prediction markets, on-chain data, market monitoring, evidence packs
- Local automation: browser helpers, Mac utilities, structured research pipelines
- Clear documentation: small tools with honest README files, demos, limits, and reproducible steps

## Principles

- Small tools over bloated demos.
- Useful README first: what it does, who it helps, how to run it, and where it breaks.
- Real contributions over contribution farming.
- Automation with human-readable evidence and clear failure modes.
